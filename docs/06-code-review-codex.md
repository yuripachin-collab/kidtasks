## Вердикт Codex (до правок)

> «До использования исправить вход/PIN, начисления и корзину, сохранность дневных снимков, обработчики запросов, ошибки коммита и повторные операции; для использования как PWA — подключение manifest и подготовку оффлайна».

## Найдено: 37 замечаний — 4 критичных, 27 важных, 6 мелких/теоретических

## Что было сломано на самом деле (критичные)

1. **Конфигурация читалась в неверной обёртке** — `state.config.pin.salt` был бы `undefined`, вход родителя не работал бы никогда. Исправлено: `getConfig` отдаёт `value`.
2. **Снятие отметки начисляло баллы вместо вычета** — двойная трата: ребёнок получает баллы за несделанную задачу. Исправлено: компенсирующая запись с минусом + проверка «не увести баланс в минус» + человеческое предупреждение «Сначала убери лишнее из корзины».
3. **Смена цены товара портила корзину** — новая единица по новой цене приклеивалась к позиции со старой ценой, возвраты считались неверно. Исправлено: позиция корзины = товар + снимок цены (ключ `productId@цена`), смена цены создаёт отдельную позицию.
4. **Снимок дня мог быть перезаписан** при возврате даты устройства — потеря отметок при сохранённой истории. Исправлено: снимок создаётся один раз, автоматически никогда не перезаписывается.

## Также исправлено (выборка)

- Кнопки баннера запроса не работали (обработчик висел не на том контейнере)
- Удаление товара из каталога не было реализовано вовсе
- `put/del` завершались до коммита транзакции; исключение в операции не прерывало транзакцию
- PIN-блокировка читалась в той же неверной обёртке; гонка проверок PIN; смена PIN не обновляла конфигурацию в памяти
- Запросы: защита от дублей, «Назначить» только по активному запросу и только с непустым списком
- День не переключался при возврате в приложение после полуночи (visibilitychange)
- Двойные клики: глобальная защита `withBusy`
- Отсутствовали `navigator.storage.persist()`, `<link rel="manifest">`, регистрация SW на первом запуске
- Service worker чистил чужие кэши домена; оффлайн-готовность теперь сообщается
- Серия 🔥: переписана на обход снимков (без 366-дневного окна); знак истории — по сумме записи
- Тема по умолчанию — светлая (по спеке); тач-зоны ≥44×44

## Принято частично / задокументировано

- Пропущенные дни серии считаются паузой (восстановление расписания — v2, добавлено в спеку §7)
