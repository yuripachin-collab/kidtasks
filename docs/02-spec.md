# Этап 2. Спецификация — «Задачки и магазин» (KidTasks)

Дата: 2026-10-26 · Ревизия: **4** (после внешнего ревью Codex — см. docs/05-codex-review.md) · Основание: docs/01-investigation.md (GO)
Статус: ✅ утверждена заказчиком

> **История ревизий:**
> **2** — корзина вместо правила выходных; задачи без дней недели; запрос «что делать?».
> **3** — в корзине несколько единиц одного товара (×N).
> **4** — закрыты 7 критичных дыр ревью: защита от минуса при снятии отметки; снимки цены в корзине; дневные снимки задач; «Назначить на сегодня» при запросе; атомарные операции; «Выдано» без повторного списания; лимит родительского списания. Плюс: родитель может убирать из корзины; сессия родителя до закрытия приложения; политика дат; лимиты ввода; тексты без обещания push.

## 1. Что строим

PWA-приложение для одного устройства (iPhone/iPad): родитель ведёт список ежедневных задач, подросток выполняет их и получает баллы, тратит баллы через корзину; родитель подтверждает выдачу наград. Без сервера, без аккаунтов, работает без интернета.

## 2. Роли

| Роль | Вход | Может |
|---|---|---|
| Подросток | без пароля | задачи «Готово», «Что мне сегодня делать?», корзина (добавить/убрать штуку), каталог, история |
| Родитель | PIN (4 цифры) | ведёт задачи и каталог, убирает позиции из корзины, «Выдано», корректирует баланс, настройки; выполняет запросы подростка. Отметки задач и набор корзины — действия подростка (родитель влияет корректировками и выдачей) — уточнено по ревью кода; кнопка «Выйти» завершает родительскую сессию |

PIN — защита от случайного входа, не от намеренного взлома (данные лежат в браузере устройства). Родительская сессия живёт до закрытия приложения; при новом открытии — всегда экран выбора роли.

## 3. Экраны

- **S0. Первый запуск.** Имя подростка, PIN родителя (4 цифры, дважды). Затем — S1.
- **S1. Выбор роли.** «Я подросток: {имя}» / «Я родитель» (→ PIN). После 5 неверных PIN — пауза 30 секунд (состояние блокировки переживает перезапуск). Забытый PIN = сброс приложения с потерей данных (двойное подтверждение).
- **S2. Подросток — Задачи** (главная). Баланс «Доступно: N ⭐» + пометка «Уже в корзине: M ⭐ (списано)», серия 🔥. Задачи на сегодня с «Готово ✓» (выполненные — зачёркнуты). Если список пуст: «На сегодня ничего не назначено» + кнопка **«Что мне сегодня делать?»** → статус **«Запрос отправлен — родитель увидит напоминание в приложении»**.
- **S3. Подросток — Магазин.** Баланс. Корзина: позиции с количеством («Шоколадка ×2 — 100 ⭐»), «✕» убирает одну штуку (цена возвращается по снимку), итог, статус «Ожидает родителя». Каталог: фото (или плейсхолдер), название, цена; «+ В корзину» / «Не хватает N ⭐».
- **S4. Подросток — История.** Движения с типами: начислено / в корзину / вернул / бонус / списано; записи «Выдано: … ×N (цена)» — справочные, баланс не меняют.
- **S5. Родитель — Задачи.** Два блока: «Сегодня: выполнение» (что задано и что сделано) и «С завтрашнего дня: изменения» (список с «Изменить/Удалить», «+ Задача»). При активном запросе — баннер с датой и кнопками **«Назначить на сегодня»** (немедленно заполняет пустой сегодня и закрывает запрос) и **«Закрыть»**.
- **S6. Родитель — Магазин.** Корзина подростка: состав с ×N, итог, кнопка **«Выдано ✓»** с подтверждением-списком (очищает корзину, пишет справочные «Выдано: …»); у родителя есть «убрать» у позиции (возврат по снимку цены). Ниже каталог: «+ Товар», «Изменить», «Удалить».
- **S7. Родитель — Баланс и история.** Баланс, «+ начислить» / «− списать» (списание ≤ текущего баланса), полная история.
- **S8. Родитель — Настройки.** Имя подростка, смена PIN (с вводом текущего), тема (светлая/тёмная/авто), «Выйти» (завершить сессию родителя), версия.

Вкладки: подросток — Задачи, Магазин, История; родитель — Задачи, Магазин, Баланс, Настройки.

## 4. Правила (бизнес-логика)

- **R1.** «Готово ✓» начисляет баллы сразу (история «Начислено»). Повторное нажатие сегодня снимает отметку и возвращает баллы — **но только если после возврата баланс не станет отрицательным**; иначе показывается «Сначала убери лишнее из корзины». Завтра отметку снять нельзя.
- **R2.** Список задач родителя — источник ежедневных задач подростка. Изменения вступают в силу **со следующего дня**; все правки за день применяются к одному завтрашнему списку (дата вступления в силу у каждой версии). **Исключение:** если сегодняшний список пуст и есть активный запрос, «Назначить на сегодня» заполняет сегодня немедленно и закрывает запрос.
- **R3.** «Сегодня» — локальная дата устройства **в момент действия**. Отметки привязаны к дате из дневного снимка; одна задача не может быть засчитана дважды за один день. Новый день определяется при открытии приложения (фонового «полночного» кода нет).
- **R4.** Серия 🔥 считается по дневным снимкам: день засчитан, если все его задачи выполнены. Незавершённый сегодня день не рвёт серию и не растит её — показывается серия на вчера. Пустой день — пауза. Завершённый неполный день (прошёл, не всё сделано) — рвёт серию.
- **R5.** Баланс = сумма истории. Ни одна операция не может сделать его отрицательным (см. R1, R6, R7).
- **R6. Корзина.** Позиция хранит **снимок**: название и цену единицы на момент добавления (смена цены товара позже не влияет на возвраты). «+ В корзину» добавляет одну единицу, если баланс ≥ её снимку-цене (история «В корзину»). «✕» подростка убирает одну штуку, возврат по снимку (история «Вернул»); родитель тоже может убрать позицию целиком (возврат по снимку). «Выдано ✓» — с подтверждением-списком; очищает корзину; в историю пишутся справочные «Выдано: … ×N (цена)» с **нулевым влиянием на баланс** (баллы списаны при добавлении).
- **R7.** Корректировка родителем: «− списать» не больше текущего баланса; сумма ненулевая; комментарий обязателен (пробелы по краям срезаются, до 100 символов).
- **R8.** Архив/удаление задач и товаров не меняет историю и баланс; в старых дневных снимках сохраняются названия и цены на момент того дня.
- **R9.** Активен один запрос «что делать?». Кнопка видна только при пустом сегодняшнем списке. Баннер у родителя содержит дату запроса и кнопки «Назначить на сегодня» / «Закрыть».
- **R10.** Каждая операция (проверка + изменение + запись истории) выполняется **одной транзакцией** хранилища с повторной проверкой условий внутри — сбой или быстрое двойное нажатие не ломают данные.
- **R11.** Лимиты ввода: баллы и цены — целые 1–999; названия — 1–60 символов (trim); комментарий — до 100 (trim); фото товара опционально (без фото — плейсхолдер). Ошибки хранилища (квота, отказ persistent) показываются сообщением; риск очистки хранилища iOS принят, экспорт резервных копий — версия 2.

## 5. Данные (IndexedDB, persistent-запрос, всё локально)

| Сущность | Поля |
|---|---|
| Задача (текущая версия) | id, название, баллы, в архиве?, дата вступления в силу |
| **Дневной снимок** | дата, список: {id, название, баллы — на момент дня}, отметки выполнения |
| Товар | id, название, цена, фото (≤512px) или плейсхолдер |
| **Корзина** | id товара, название-снимок, цена-снимок за единицу, количество |
| История | id, тип (начислено / в корзину / вернул / выдано(0) / бонус / списано), сумма, название или комментарий, дата-время |
| Настройки | имя подростка, солёный хеш PIN, тема, состояние блокировки PIN |
| Запрос «что делать?» | дата, закрыт? |

Миграции хранилища — с сохранением истории. Хеш PIN — с солью (PBKDF2).

## 6. Интерфейс и язык

- Русский. Пользователь — подросток ~14 лет: чистый «взрослый» интерфейс.
- Светлая тема по умолчанию, тёмная — настройка. Баллы — ⭐. Кнопки — настоящие кнопки с тач-зоной ≥44px.
- Ставится на домашний экран; после установки работает без сети (о готовности оффлайна — индикатор при первой установке).

## 7. Не входит в MVP (отложено)

Несколько детей; фото-подтверждение; синхронизация устройств; экспорт резервных копий; уровни/значки; настоящие push; пароль на роль подростка; поштучная выдача корзины; защита данных от намеренно взламывающего владельца устройства; **восстановление пропущенных дней серии** (день, когда приложение не открывали, считается паузой — зафиксировано по ревью кода).

## 8. Критерии приёмки (основа тестов этапа 5)

1. Первый запуск: имя + PIN → выбор роли; reopen приложения → всегда выбор роли.
2. PIN: 5 неверных → пауза 30 сек, состояние переживает перезапуск; смена PIN требует текущего.
3. Правка списка сегодня → подросток видит её завтра; сегодняшний список не меняется.
4. «Готово» начисляет сразу; снятие сегодня возвращает баллы; завтра снять нельзя; **снятие, уводящее баланс в минус, блокируется с подсказкой**.
5. Серия: растёт после полного дня; незавершённое сегодня её не рвёт и не растит; неполный прошедший день рвёт; пустой — пауза.
6. Пустой список → «Что мне сегодня делать?»; у родителя баннер с датой; «Назначить на сегодня» заполняет сегодня немедленно и закрывает запрос; «Закрыть» убирает баннер.
7. «+ В корзину» списывает цену единицы; ×N накапливается; «✕» возвращает по снимку цены — в т.ч. **после изменения цены товара**.
8. «Не хватает N ⭐» при нехватке; минус невозможен ни одной операцией (включая «− списать» родителя).
9. «Выдано ✓» → подтверждение-список → корзина пуста, справочные «Выдано» в истории, баланс не меняется повторно.
10. Родитель может убрать позицию из корзины (возврат по снимку).
11. Корректировка с комментарием видна в истории подростка; списание > баланса невозможно.
12. Архив/удаление задач и товаров не меняет историю; старые снимки показывают старые названия/цены.
13. Полночный переход: отметки «вчерашнего» дня больше не снимаются, серия пересчитывается по снимкам при открытии.
14. Перезапуск приложения и перезагрузка iPhone — все данные на месте; ошибки хранилища показываются сообщением.
15. Ставится на домашний экран; работает без сети после первой установки; обновление версии подхватывается.
16. **Проверка на реальном iPhone**: установка, фон/возврат, перезапуск, офлайн, фото, сохранность данных.
