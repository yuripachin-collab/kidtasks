# Этап 2. Спецификация — «Задачки и магазин» (KidTasks)

Дата: 2026-10-26 · Ревизия: **2** (правки заказчика в тот же день) · Основание: docs/01-investigation.md (GO)
Статус: ✅ утверждена заказчиком

> **Что изменилось в ревизии 2:**
> 1. Правило «траты только в выходные» заменено **корзиной**: подросток добавляет товары в любое время, баллы списываются при добавлении и возвращаются при удалении; родитель выполняет корзину кнопкой «Выдано».
> 2. Задачи больше не привязаны к дням недели: список родителя — ежедневные задачи подростка; изменения родителя вступают в силу **со следующего дня**.
> 3. Новое: кнопка подростка **«Что мне сегодня делать?»** — если список на день пуст, родитель получает напоминание.
> 4. Убрана «копилка» (прогресс к конкретному товару) с главного экрана.

## 1. Что строим

PWA-приложение для одного устройства (iPhone/iPad): родитель ведёт список ежедневных задач, подросток выполняет их и получает баллы, баллы тратит через корзину; родитель подтверждает выдачу наград. Без сервера, без аккаунтов, работает без интернета.

## 2. Роли

| Роль | Вход | Может |
|---|---|---|
| Подросток | без пароля | задачи «Готово», «Что мне сегодня делать?», корзина (добавить/удалить), магазин-каталог, история |
| Родитель | PIN (4 цифры) | всё то же + вести задачи и каталог, выполнять корзину, корректировать баланс, настройки |

## 3. Экраны

- **S0. Первый запуск.** Имя подростка, PIN родителя (4 цифры, дважды). Затем — S1.
- **S1. Выбор роли.** «Я подросток: {имя}» / «Я родитель» (→ PIN). После 5 неверных PIN — пауза 30 секунд.
- **S2. Подросток — Задачи** (главная). Вверху: баланс ⭐ (и пометка «ещё N ⭐ в корзине»), серия дней 🔥. Ниже: задачи на сегодня (название, +баллы, «Готово ✓»; выполненные — зачёркнуты). **Если список пуст:** карточка «На сегодня ничего не назначено» + кнопка **«Что мне сегодня делать?»** → статус «Запрос отправлено ✓» (родитель увидит напоминание).
- **S3. Подросток — Магазин.** Баланс. **Карточка корзины**: товары с ценами, у каждого «✕» (убрать — баллы вернутся), итог и статус «Ожидает родителя». Ниже каталог: фото, название, цена; кнопка «+ В корзину» / «В корзине ✓» / «Не хватает N ⭐».
- **S4. Подросток — История.** Все движения: «+15 Задача», «−50 В корзину», «+50 Убрал из корзины», «−80 Куплено: …», «+10 Бонус» с датой и временем.
- **S5. Родитель — Задачи.** Список задач (название, +баллы, «Изменить», «Удалить»), кнопка «+ Задача». Если есть запрос подростка — баннер «Юра спросил, что делать сегодня» с кнопкой «Назначить». Пояснение на экране: изменения увидит подросток **с завтрашнего дня**.
- **S6. Родитель — Магазин.** Сверху — **корзина подростка**: состав, итог, большая кнопка **«Выдано ✓»** (корзина пустеет, в историю пишется «Куплено: …»). Ниже каталог: «+ Товар» (фото из галереи/камеры, название, цена), «Изменить», «Удалить».
- **S7. Родитель — Баланс и история.** Баланс, «+ начислить» / «− списать» (сумма + обязательный комментарий), полная история.
- **S8. Родитель — Настройки.** Имя подростка (изменить), смена PIN, тема оформления (светлая / тёмная / как в системе), версия приложения.

Навигация: вкладки внизу. Подросток: Задачи, Магазин, История. Родитель: Задачи, Магазин, Баланс, Настройки.

## 4. Правила (бизнес-логика)

- **R1.** «Готово ✓» начисляет баллы сразу (запись в историю). Повторное нажатие снимает отметку и возвращает баллы — только сегодня; назавтра отметка не снимается.
- **R2.** Список задач родителя — ежедневные задачи подростка. Любое изменение списка (добавить/изменить/удалить) вступает в силу **со следующего дня**: сегодняшний список подростка не меняется посреди дня. Отметки «Готово» обнуляются каждую ночь.
- **R3.** «Сегодня» — по календарю устройства (местная дата).
- **R4.** Серия 🔥 = число дней подряд (заканчивая сегодня), когда выполнены **все** задачи дня. Если список на день пуст — серия не растёт и не обнуляется (пауза).
- **R5.** Баланс = сумма всех записей истории. Хранится вычислением, поэтому потерять баланс или уйти в минус невозможно.
- **R6. Корзина.** «+ В корзину» доступен, если баланс ≥ цены; баллы списываются немедленно (история «В корзину: …»). «✕» убирает из корзины и возвращает баллы (история «Вернул: …»). «Выдано ✓» у родителя очищает корзину; по каждому товару — история «Куплено: …». Убрать товар из корзины может только подросток.
- **R7.** Корректировка родителем: любая ненулевая сумма + обязательный комментарий (до 100 символов). В истории: «Бонус: …» / «Списано: …».
- **R8.** Архив/удаление задач и товаров не меняет прошлую историю и баланс.
- **R9.** Кнопка «Что мне сегодня делать?» видна только при пустом списке на сегодня. Нажатие создаёт напоминание родителю (баннер на родительских экранах + отметка), которое живёт, пока список не назначен или родитель не скинул напоминание.

## 5. Данные (хранятся в браузере, IndexedDB, persistent-режим)

| Сущность | Поля |
|---|---|
| Задача | id, название, баллы, в архиве? |
| Товар | id, название, цена, фото (сжатие до ~512px) |
| Корзина | id товара, дата добавления |
| Запись истории | id, тип (начислено / в корзину / вернул / куплено / бонус / списано), сумма, название или комментарий, дата-время |
| Настройки | имя подростка, хеш PIN, тема |
| Запрос «что делать?» | дата последнего запроса, закрыт? |

PIN — только хешем. Всё работает без сети.

## 6. Интерфейс и язык

- Язык — русский. Пользователь — подросток ~14 лет: чистый «взрослый» интерфейс, без маскотов и «детсадовских» приёмов.
- Светлая тема по умолчанию, тёмная — настройка. Баллы — значком ⭐.
- Ставится на домашний экран, открывается без адресной строки.

## 7. Не входит в MVP (отложено)

Несколько детей; фото-подтверждение выполнения; синхронизация между устройствами; экспорт резервной копии; уровни и значки; **настоящие push-уведомления** (напоминание о запросе живёт внутри приложения — на одном устройстве этого достаточно); пароль на роль подростка; количество одного товара больше 1 в корзине.

## 8. Критерии приёмки (основа тестов этапа 5)

1. Первый запуск: имя + PIN → выбор роли.
2. PIN: 5 неверных — пауза 30 секунд.
3. Родитель добавил задачу сегодня → подросток видит её **завтра**, сегодняшний список не изменился.
4. «Готово» начисляет сразу; снятие отметки сегодня возвращает баллы; завтра снять нельзя.
5. Серия 🔥 растёт только при всех выполненных задачах дня; при пустом списке не сбрасывается.
6. Пустой список → кнопка «Что мне сегодня делать?»; после нажатия родитель видит баннер; после назначения задач баннер исчезает.
7. «+ В корзину» списывает баллы; «✕» возвращает; баланс никогда не уходит в минус.
8. Добавление в корзину дороже баланса невозможно («Не хватает N ⭐»).
9. «Выдано ✓» очищает корзину и пишет «Куплено: …» по каждому товару.
10. Корректировка родителя с комментарием видна в истории подростка.
11. Архив/удаление задач и товаров не меняет историю и баланс.
12. Перезапуск приложения и перезагрузка iPhone — все данные на месте.
13. Ставится на домашний экран, работает без интернета.
