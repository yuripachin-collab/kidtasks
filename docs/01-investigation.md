# Этап 1. Investigation — «Задачки и магазин»

Дата: 2026-10-26 · Роль: агент-аналитик (Claude) · Статус: ✅ GO

## 1. Идея в одном абзаце

Приложение «родитель ↔ ребёнок». Родитель ставит задачи на день, ребёнок выполняет их и отмечает выполнение, зарабатывая баллы. Баллы копятся за неделю и тратятся в выходные во «внутреннем магазине»: родитель сам добавляет товары — фото, название, цена в баллах (реальные награды вроде сладостей, которые родитель покупает/выдаёт вживую).

## 2. Кому и зачем

- **Родителю:** перестать уговаривать. Правила «задача → баллы → награда» зафиксированы в приложении, ребёнок мотивирован сам, а не обещаниями.
- **Ребёнку:** понятная игра — виден прогресс, серия дней и цель, на которую копишь. Награда не абстрактная («хорошее поведение»), а конкретная: «три дня задач = шоколадка».

## 3. Конкуренты

| Приложение | Модель | Сильное | Слабое |
|---|---|---|---|
| OurHome (классик жанра) | было бесплатно | эталонная механика: задачи → баллы → магазин, оценка от родителей | по обзорам 2026 проект фактически исчез/переродился — семьям нужны замены |
| PointUp | подписка $3.99/мес | лучший геймификатор: уровни, значки, серии; **магазин наград с фото от родителей**; режимы для СДВГ | бесплатный тариф урезан (5 задач, 3 человека) — всё главное за paywall |
| Chores Hero | freemium | баллы, серии, магазин, подтверждение родителем; **«полностью бесплатно на одном устройстве»** — ровно наша модель | синхронизация между устройствами платная ($4.99/мес) |
| Joon | только подписка | виртуальный питомец, растёт от выполненных задач; хит для детей 6–12 | если питомец «не зашёл» — возвращаться не за что; подростки перерастают |
| Homey | freemium | «баночки» тратить/копить/делиться | оценка 2.8 на Android: баги, задачи слетают; слабая мотивация |

| Neat Kid | freemium | просто,-setup за 5 минут, малыши 4–7 лет | «10-летний видел всё это уже через месяц» — нет серий, уровней, целей |

## 4. Выводы из анализа

1. **Механика проверена рынком.** «Задачи → баллы → магазин» — ядро самых любимых детьми приложений (OurHome, PointUp, Chores Hero). Мы не изобретаем — мы воспроизводим работающее.
2. **Ниша свободна.** Главный бесплатный эталон (OurHome) исчез, оставшиеся давят подписками: почти во всех «бесплатных» приложениях нужные семьям функции (магазин наград, синхронизация, подтверждение родителем) заперты за paywall — главная боль родителей в отзывах.
3. **Магазин с фото — редкость.** Из 9 сравненных приложений магазин наград с товарами, созданными родителем, полноценно есть только у PointUp (платно). Это наша центральная фича.
4. **Дети хотят игру, а не таблицу.** Простые чек-листы дети «выедают» за месяц; удерживают серии дней, уровни и накопление к видимой цели.
5. **Модель «одно устройство — бесплатно» рабочая.** Chores Hero живёт именно так: одно устройство бесплатно, синхронизация — платная надстройка. Подтверждает наш выбор MVP.

## 5. Чем наше приложение будет отличаться

- Полностью бесплатное, данные только на устройстве пользователя, без аккаунтов и подписок.
- Магазин с фото товаров — центральная фича, а не огрызок.
- Настраиваемое правило трат: «только выходные» / «в любой день» (у большинства конкурентов такого правила нет вообще).
- Серии дней + магазин: то, чего детям не хватает в простых приложениях.

## 6. Решения по объёму MVP (нужно подтверждение)

| # | Вопрос | Рекомендация |
|---|---|---|
| 1 | Одно устройство, роли «родитель/ребёнок»? | Да. Вход родителя — по PIN |
| 2 | Сколько детей? | Один ребёнок в MVP; несколько детей — версия 2 |
| 3 | Родитель подтверждает каждую выполненную задачу? | Нет: баллы начисляются сразу, родитель может скорректировать баланс вручную (фото-подтверждение — версия 2) |
| 4 | Типы задач | Разовые и повторяющиеся по дням недели |
| 5 | Траты только в выходные? | Настраиваемо: режим «только выходные» / «в любой день» |
| 6 | Непотраченные баллы | Копятся бессрочно; в истории видно «заработано / потрачено» |

## 7. Риски

| Риск | Как снижаем |
|---|---|
| Ребёнок отметит задачу, которую не делал | MVP: родитель видит историю и может снять баллы; версия 2: фото-подтверждение |
| iOS в редких случаях может очистить хранилище браузера | Версия 2: экспорт резервной копии (файл). В MVP — хранение в надёжном (persistent) хранилище браузера |
| Ребёнку быстро надоест, если нет прогресса | Серии дней + видимый прогресс накопления к товару из магазина |
| У пользователя двое детей | Ограничение MVP, честно указать; несколько детей — первая версия 2 |
