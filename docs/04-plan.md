# Этап 3. План и архитектура — «Задачки и магазин» (KidTasks)

Дата: 2026-10-26 · Роль: архитектор (Claude) · Референс: Kids Task & Reward App, Emote Agency (`assets/reference/`)
Статус: ✅ готов, ждёт «поехали» на этап 4

## 1. Технологии (и почему именно так)

- **Чистые HTML + CSS + JavaScript. Без фреймворков и без сборки.**
  Почему: приложение из ~9 экранов — фреймворк тут не окупается; ноль зависимостей = ноль поломок «из ниоткуда»; любой агент (я, Кодекс, GLM) работает с кодом без настройки окружения; деплой = просто скопировать файлы на хостинг.
- **Данные: IndexedDB** — хранилище браузера: переживает закрытие и перезагрузку, помечается как постоянное (persistent).
- **Оффлайн: service worker** — при первой установке кэширует все файлы приложения.
- **Тесты (этап 5):** Node.js + Playwright (автоматически щёлкает приложение как живой человек). Node поставим в начале этапа 5 — до этого он не нужен.

## 3. Дизайн-токены

Палитра снята с референса программно (tools/palette.py по картинке): воздушный светло-голубой фон (37% площади референса) + белый (44%), тёмный текст, акценты: изумруд, розовый, сиреневый, золото монет. Для подростка приглушили «конфетность»: розовый/сиреневый — только как-functional акценты, основные действия — изумруд.

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#EDF3FA` | фон экрана |
| `--surface` | `#FFFFFF` | карточки |
| `--ink` | `#1F2430` | основной текст |
| `--muted` | `#77839B` | вторичный текст |
| `--accent` | `#10A070` | действия («Готово», «Купить») |
| `--accent-soft` | `#E2F5EE` | подложки успеха |
| `--coin` | `#F2A93B` | баллы ⭐ |
| `--pink` / `--violet` | `#EF7FA3` / `#8B7CF6` | бейджи, магазин, баннеры |
| радиусы | 22 / 16 / 12 | карточки / строки / кнопки |
| шрифт | системный (SF Pro) | apple-стиль, мгновенная загрузка |

Тёмная тема — те же роли в тёмных значениях (таблица соответствия появится в tokens.css на этапе 4, пункт 6 плана работ).

## 5. План этапа 4 (кодинг) — 7 шагов

| # | Шаг | Готово, когда… |
|---|---|---|
| 1 | Скелет: оболочка, токены, вкладки, пустые экраны | открывается, вкладки переключаются |
| 2 | Хранилище + онбординг (имя, PIN) | данные переживают перезагрузку Mac |
| 3 | Экран подростка: задачи, «Готово», правила R1–R3 | баллы начисляются, история пишется |
| 4 | Магазин + корзина подростка (R5–R6) | критерии приёмки 7–9 выполняются |
| 5 | Родительская часть (S5–S8) | критерии 3, 6, 10, 11 выполняются |
| 6 | Серия 🔥 (R4) + тёмная тема | критерий 5 выполняется |
| 7 | PWA: manifest, иконка, оффлайн | ставится на домашний экран, работает без сети (критерии 12–13) |

После каждого шага — коммит. После шагов 3 и 5 — ревью Кодексом.
