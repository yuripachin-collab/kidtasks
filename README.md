# KidTasks — «Задачки и магазин» (рабочее название)

Учебный MVP: приложение «родитель ↔ подросток». Родитель ведёт список ежедневных задач, подросток выполняет и зарабатывает баллы, тратит их через корзину наград (фото + цена в баллах), которую родитель выполняет кнопкой «Выдано».

- Платформа: PWA (ставится на iPhone с домашнего экрана, без аккаунта разработчика)
- Одно устройство, две роли (родитель — по PIN)
- Все данные хранятся на устройстве, без сервера
